# 日本語表示テキストの確認・変更

画面に使う固定文言とメッセージのテンプレートは、`data/text/ja`にまとめています。

| JSON | 内容 |
| --- | --- |
| `ui.json` | HOME、出撃、Skill、Lv強化カード、加護比較、作戦報告書の見出し・説明・操作 |
| `application.json` | 能力・技能・費用・対象条件などの表示情報 |
| `history.json` | 成長・選択・出撃結果の記録と結果表示 |

JSONの左側はプログラムから参照する固定キー、右側は表示する日本語です。確認・修正する際は右側を編集します。`{0}`、`{1}`などには名前や実際の数値が入り、`{0:0.##}`のような指定には表示書式も含まれます。プレースホルダーは個数と番号を保持してください。JSONの改行は`\n`、引用符は`\"`で表します。

例：`"ui.example": "{0}のHP：{1}/{2}"`は、対象名・現在HP・最大HPを差し込むテンプレートです（説明用で、実際のキーではありません）。

文言は`Guild.Application.DisplayText`が埋込リソースとして読み、ApplicationとGodotが共用します。ソースJSONの変更後は再ビルド・配布が必要です。配布ZIPにも確認用のJSONを同梱していますが、そのコピーだけを書き換えても起動中の表示は変わりません。

武器・技能・加護・ステージの固有名とゲーム定義値は従来の`data/tech-content.json`が正本です。UIカタログに戦闘ルールを移していません。内部ID、保存データ形式、試験用メッセージ、障害調査用の例外文は表示カタログと区別します。

文言を変更しても、タブや行動状態の判定には固定コードを使うため、ゲーム進行は変わりません。未定義キー・重複キー・壊れたテンプレートは検証で検出します。
