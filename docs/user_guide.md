# v0.3.0 操作ガイド

[v0.3.0の公開ページ](https://github.com/Tao-pyth/the-conductor-of-the-guild/releases/tag/v0.3.0)から `TheConductorOfTheGuild-0.3.0-windows-x64.zip` を入手して展開し、フォルダー内の `TheConductorOfTheGuild.exe` を起動します。関連ファイルは同じフォルダーに保持してください。.NET SDKやGodotエディターを別途入れる必要はありません。

## 侵攻モード

1. 拠点の出撃から侵攻ステージを選びます。編成画面で所有冒険者から1〜10名を選び、出撃を確定します。固定ジョブはなく、武器・能力・加護を引き継ぎます。
2. 準備画面では左側の出撃マスへ冒険者を配置します。最低1名が必要です。初配置はマッチ資源を使い、配置済み冒険者の位置変更は区画間に無料で行えます。
3. 侵攻開始後は各自で進軍・攻撃します。前後の初期位置を決められますが、進軍中の速度差で並びは変わります。
4. 攻撃優先を「近い敵」「HPが低い」「HPが高い」「設備優先」から選べます。設備優先も、接近・攻撃できる相手が対象です。発射済みの弾は途中の敵に当たることがあります。
5. 守備兵・砲台と門をすべて倒すと区画突破です。次の区画で、位置変更・控えの初配置・Lv購入・復帰を行えます。HP・技能の待ち時間・強化・状態異常は引き継ぎ、準備中は時間が止まります。
6. 戦闘不能者を復帰させるとLvを保持し、未使用XP・一時強化・状態異常・未選択強化は消えます。通常技能は準備済み、ULTは待機へ戻ります。復帰後にLv購入を行ってください。
7. 中枢の守備隊と司令核を倒せば勝利です。帰還すると拠点資源・武器・Rank経験値・HP/衰弱等を一度だけ確定します。

戦闘中の追加出撃・再配置・復帰はできません。**部隊が全滅すると、控えが残っていても敗北**です。各区画は戦闘時間300秒で時間切れ。一時停止中は進まず、2倍速では速く進みます。同じ更新で全滅と拠点破壊が重なった場合は敗北、全滅せず拠点攻略と時間切れが重なった場合は勝利/突破です。途中撤退はありません。

3区画の突破XPは最大150です。Lv成長を早めたい場合は、区画間に次Lvへの不足XPを購入します。敵性能や報酬は技術検証の初期値で、正式バランスの完成を意味しません。

## 拠点

- 左側の一覧から冒険者を選択します。名前欄と変更ボタンで日本語名を保存できます。
- 装備は所有者ごとに管理します。冒険者は本人が所有する武器へ装備変更できます。
- ユーザー所有の装備は、Rankイベントの「装備を譲渡」で対象冒険者へ渡します。返却・冒険者間移動はありません。
- 募集は資源100。初期は6名を支給済み、拠点資源0です。所有枠は10名、拡張は5名ずつ最大50名です。
- 武器購入は予算100に対応する資源1000を使い、完成した生成値と技能割当を保存します。
- 成長履歴は実行順に閲覧できます。Rankイベントを未選択のまま保留して出撃することもできます。

## 防衛モードとWave

1. 出撃すると準備画面になります。冒険者を選んで、経路外の空いているマスをクリックします。
2. 同時配置は最大10名、Wave開始には1名以上の配置が必要です。
3. 「Wave開始」で戦闘を進めます。標的の選び方、一時停止、1倍・2倍速を切り替えられます。
4. Wave間は既存配置者の再配置が無料です。Lv経験値は次Lvへの不足分をまとめて購入できます。
5. Lv強化が提示されたら3候補から1つ選びます。一時強化はそのマッチでだけ有効です。
6. 戦闘不能者はWave間に復帰できます。Lvを保持し、通常技能は準備済み、ULTは待機状態へ戻ります。

表示される配置・復帰費用や報酬には、技術検証用の調整値を使っています。

## 勝敗と成長

- 最終Wave防衛後、帰還すると拠点資源・Rank経験値・HP回復等を1回確定します。
- 敗北後は再挑戦か帰還を選びます。再挑戦では同じ開始構成を新しい試行として使い、帰還時に最終試行を精算します。
- Rank上昇で保留されたイベントでは、加護・装備譲渡・合成・ランダムイベントから1つ選びます。種類を選んだ後は完了まで継続します。
- 通常加護は取得・進化・入れ替え・全候補破棄を選べます。III所有済みは抽選から除外します。
- ランダム加護も取得・進化・入れ替え・辞退を選べます。通常の破棄ボーナスは変えません。
- 合成には対応する異種加護2つのIIIが必要です。未発見結果は実行後に公開し、以後も発見記録を保持します。

## 保存と再開

確定操作は自動保存です。防衛の戦闘中に終了した場合は現在Wave、侵攻では現在区画の開始点から、同じ試行として再開します。準備中の購入・復帰・配置・Lv選択と、選択済みRankイベントは保存された途中状態を使います。敗北後の再挑戦は、最初のWave/区画の開始直前へ戻します。

通常の保存先は `%APPDATA%/Godot/app_userdata/The Conductor of the Guild/guild-save.sqlite3` です。ZIPの場所を変えても同じユーザーの保存先を使います。

更新後も進行中マッチは開始時の定義を使用し、次の出撃で新しい技能定義を適用します。生成済み武器の値と搭載IDは保持します。

旧版の保存を初めて開く際は、同じフォルダーへ `.before-documents-v2-...backup` を作成してから、プロフィールとマッチを文書形式2へまとめて移行します。生成済み装備や進行中の防衛を引き継ぎます。未対応の将来形式や破損が見つかった場合は、元の保存を変更せず読み込みを中止します。

v0.2.0へ戻す場合は、アプリを閉じ、移行後の保存も別名で保管してから移行前バックアップを復元してください。バックアップは移行前の時点のデータなので、それ以後の進行は含みません。移行済みの保存は旧版が拒否します。通常の再起動・再開ではバックアップへ戻す必要はありません。

## 現在の検証範囲

表示と名前変更経路はWindows上で確認済みです。日本語文字を入力し、変更ボタンから保存して、別プロセスで再起動しても名前が維持されることを検証しています。OSの日本語IMEによる変換・候補確定は未確認です。

処理負荷と通常デモのFPSを測定しています。描画を含む最大負荷や、すべてのPCで60fpsになることは保証していません。測定条件は [検証結果](verification.md) を参照してください。

収録データは防衛1ステージ10Wave、侵攻1ステージ3区画、5武器種、5技能、3加護、1合成レシピの技術検証セットです。防具・装飾品、個性プロフィール、UNIQUEの性能調整、祓いの雫による浄化は今後の製品範囲です。これらを今回実装済みとは扱いません。
