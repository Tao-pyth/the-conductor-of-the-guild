## 1. 確定条件と本案の範囲

合成素材は異なる2種類の加護で、どちらもRank III。素材2個とRankイベント1回から、加護1個・1枠・Rank Iを生成する。失敗や追加通貨・アイテム消費はなく、加護RankはIIIまで・例外なし。多段階合成を認める。これらは確定条件であり、本案で新たに変更しない。

「通常」「上位」「UNIQUE」は加護の種類・性質を表す区別であり、加護Rank I〜IIIの上に新しいRankを増やすものではない。H101であってもRankはI〜IIIのみ。レシピを何段階経ても、生成物はIから始まる。

本台帳は通常103種類のIDと非UNIQUE上位150件のレシピを一意に定義する。各レシピは親素材の全効果成分を継承する共通規約で決まり、戦術欄の説明から新しい発動行動・自動回復・状態異常付与・反撃・貫通等を追加しない。既にその行動を持つ構成の数値を強化するだけの行も含む。

## 2. 効果を継承する共通規約

### 2.1 Rank別の圧縮係数

素材A・BのRank IIIでの効果成分集合をそれぞれV(A,III)、V(B,III)とする。本案では生成Hの効果量を次で定義する。

- V(H,I) = 2/3 × Merge(V(A,III), V(B,III))
- V(H,II) = 1 × Merge(V(A,III), V(B,III))
- V(H,III) = 4/3 × Merge(V(A,III), V(B,III))

これは既存の「Iでは維持〜やや減、IIでは維持〜上昇」に対応する数値案。係数そのものは確定要件ではない。素材に上位加護を使う場合は、その素材自身のIIIの定義済み成分を一度だけ参照する。元の通常素材へ戻して同じ係数を二重適用しない。

例：H001はSTR+6とVIT+6を素材IIIから受け継ぎ、Iで各+4、IIで各+6、IIIで各+8となる。H051はH001のIII（STR+8・VIT+8）とN013のIII（物理攻撃+15%）から生成し、IはSTR/VIT各+16/3・物理攻撃+10%。内部ではこの有理数を保持し、キャラクターの最終値を求める段階で原則整数にする。合成のたびの早期切り捨てで成分を失わせない。

### 2.2 成分の型・条件・基礎分

各成分は、対象パラメータ、補正段階、単位、符号、条件、補償との対応を持つ。

1. 固定値、加算型割合、乗算型補正を混ぜない。同じ対象・同じ段階・同じ単位・同じ条件の固定値/加算型割合だけを合算する。
2. 条件付きと無条件を合算しない。剣装備時STRと無条件STR、槍装備時DEXと弓装備時DEXなどは別成分として保持する。
3. 比率の基礎1倍、キャラクターの基礎能力、武器の基礎威力、発動条件を圧縮係数で縮めたり増やしたりしない。拡縮するのは加護が与える差分だけ。
4. 乗算成分がある場合は1+δという差分形で保持し、拡縮はδへ行う。別々の乗算因子は別因子として保持し、実際の計算時に積を取る。中立の1を合成の数だけ増やさない。
5. 負補正と、その代償に対応する正の補償を両方継承する。補償だけを抜き出さない。基礎分や補償を、名称・戦術説明から追加しない。
6. 同じ通常系統が複数の枝に現れても、その枝で実際に消費した素材の効果として各1回分だけ数える。生成側が素材・合成前の親効果を別途保持することはない。
7. 98系統の代償補償は、下限等によって実際に負補正が適用されない割合だけ補償も縮小する既存の案を引き継ぐ。その判定用の対応関係はMerge後も失わない。
8. すべてのレシピが通常→H001〜050→H051〜100→H101〜150の参照方向に従い、循環しない。資源消費なしで同じ材料へ戻して再合成する経路は追加しない。

単位を分ける例：H031「一念」は、警戒範囲−10%、会心倍率の固定差分+10ポイント、会心倍率への相対割合+10%という3成分をIで持つ。後ろ2つを単に「会心倍率+20%」へまとめない。元倍率150%なら固定差分後160%、相対割合後176%となる候補計算である。

補正順と上下限制限は、固定値加算→加算型割合→乗算型の各段階で適用する。内部の成長蓄積を削除せず、計算値だけ制限する既存条件を維持する。

## 3. 通常加護N001〜N103の登録

### 3.1 Rank量と補償記号

正負の名称だけでは有利不利を判断しない。例えば攻撃間隔は下がる方が有利である。数値を上げる加護と下げる加護を別IDにし、不利方向には元案の補償を付ける。

| 規則 | Rank I / II / IIIの量 | 補正段階・単位 |
| --- | --- | --- |
| A | 2 / 4 / 6（固定値） | 固定値 |
| B | 5% / 10% / 15%（基準値に対する加算型割合） | 加算型割合。相対割合とポイント差分を区別 |
| C | 1 / 2 / 3ポイント（会心率の固定差分） | 固定差分（ポイント） |
| D | 5 / 10 / 15ポイント（会心倍率の固定差分） | 固定差分（ポイント） |
| E | 10% / 20% / 30%（持続倍率への加算型割合） | 加算型割合。相対割合とポイント差分を区別 |
| F | 3 / 6 / 9ポイント（耐性の固定差分） | 固定差分（ポイント） |

表の±は登録行の上昇・下降方向を示す。補償の「+B/2」はB量を2分割、「+B/4」は4分割する。例えばIIIの+B/2は各+7.5%であり、各対象へ+15%ずつを与えるものではない。耐性への補償はF、基礎能力値への補償はAを使う。

K1は「投射物条件でのみ与ダメージ倍率へ加える差分」、K2は「支援で与える数値補正の量へ加える差分」。この2つは元の補償先の呼び名であり、投射物を生成する能力や新しい支援行動を与えない。

名称は旧通常案を継承している。N052「易毒の回復」の補償は毒効果量、N054「重足の守り」は鈍足効果量、N056「朦朧の豪腕」は気絶効果量であり、名称から回復・防御・STR等の別効果を追加しない。正式な効果は下表を優先する。

## 7. UNIQUE台帳との接続と、未確定の境界

UNIQUE側は同じN001〜N103・H001〜H150を参照する。UNIQUE50件を合わせた全200レシピでも、順序を問わない素材ペアを重複させない。通常・上位を素材にする各レシピも、素材が異なる2種類であることを守る。

次は本台帳の作成で勝手に確定しない。

- 同名の生成結果を既にRank IIIで所有する場合の合成可否・進化不能時の消費処理。
- レシピ発見条件「保有冒険者が存在する」の保有対象。
- 初期抽選にどの上位を含めるか、加護Rankと内部希少度の具体的な重み式、区分配分の採否・端数処理。
- 資源量・候補数・抽選重みへ冒険者の加護を作用させる適用先。既存の戦闘49候補とは別の確認事項。
- 通常の正負の補償や多段階圧縮が最終的に適切な性能になるか。名称だけで効果の強さを保証しない。

本台帳の150件はすべて非UNIQUE上位で、数値成分の継承だけを持つ。独自の発動能力はUNIQUE側に分ける。加護数を増やすことを、コード実装・Issue登録・リリース範囲の決定とみなさない。
