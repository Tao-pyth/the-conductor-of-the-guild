## 1. 穴の判定と作成方針

生の成分キーがないことだけを穴とは判定しない。SKILL_*の直接指定は、対象SkillIDが割当可能な実slotの概念パラメータへ対応づけ、上位・UNIQUEが継承する素材数値も数える。そのうえで、汎用化されていない作用先と片方向の経路を分けた。

| 既存の範囲 | 判定 | 今回の対応 |
| --- | --- | --- |
| P01〜P49 | N001〜098で数値上昇/下降の両方向が既にある。武器条件5件も存在。 | 基礎値や火水属性の名称替えを増やさない。 |
| 技能の威力・回復・弱体・持続・CD・始動 | SN001〜024に正方向/有利方向がある。直接ID成分も対応ありとして数える。 | 8系統×3実slotの逆方向と補償を24案。 |
| 技能支援量 | SN048等の特定IDには対応。実slot汎用の直接ルートは不足。 | 正負×3実slotの6案。 |
| 技能範囲寸法 | SN050は拡大。P49支援範囲やSUの個別形状変更とは別。 | 汎用縮小1案。 |
| 技能対象数 | 数値の入力経路がなく、現定義のtargetCapと固定最終上限の境界に注意が必要。 | 正の対象加算3案を条件付き保留。 |
| K2支援量 | N098の代償連動補償とその継承がある。完全未対応ではない。 | 加護由来だけに限定した独立正負2案。 |

K1は補償正方向の既存対応を認め、独立正負は未作成の穴[GAP006](#gap006)として残す。

新UNIQUEや新レシピは作らない。今回は既存の数値入口を埋めることを優先し、36件を収録義務や固定の最適値にしない。代償付き案が既存の無代償加護に常に劣らないよう、補償量に差を付けた。例えば物防8/16/24%はN017の5/10/15%より大きい一方、対象slotのCD延長を引き受ける。これは性能検証済みという意味ではなく、選択理由を作るための候補値。

各IDの範囲は、BP001〜024=技能逆方向、BP025〜030=技能支援量、BP031=範囲縮小、BP032〜034=対象数、BP035〜036=加護支援量。

## 2. 全案の適用規約

- 加護6枠・Rank I〜III上限を維持。BPは種類IDであって新Rankではない。個性の枠へ流用せず、現時点ではどの取得候補にも投入しない。
- S1/S2/ULTは実割当欄。通常SkillIDをS1/S2へ重複搭載でき、両欄のCD・castは独立する。由来分類・武器ラベルを新しい装備条件にしない。
- 同じ成分がSkillID条件とslot条件に一致しても同じ欄へ1回だけ。1castの多段/範囲/継続tickを新使用に数えず、派生効果から再発動・還元・資源等を発生させない。
- `倍率差分+0.03`は基準1へ足す量で、最終1.03。`−3%`の倍率差分は元の効果量を0.97倍にする意味で、弱体率や支援値へ−3ポイントを直接引く意味ではない。固定秒・固定ポイント・加算型割合・倍率差分を合算しない。
- 逆方向の数値低下には補償を対応させる。各案の代償付き成分は同じ条件で結び付け、代償が実際に生じない空欄・無効成分・Clamp状態では補償だけを得ない。補償側に有効な成分がなく純デメリットだけになる組合せも適格対象外にする。
- CDは固定→割合→回復速度除算と各段階Clamp。固定延長はCD_FIXED_DELTAの正値、割合延長は正のcd_extension_ratio。下限0のcd_reduction_ratioへ負値を入れる代用はしない。
- 回復速度はClamp(1＋差分合計,0.25,3)。始動短縮率はrを先に−1〜0.5へClampし、速度=1/(1−r)、元始動/速度。元始動0・共通硬直・CD床を変更しない。
- 威力/回復0.1〜5、弱体/支援量0.1〜3という確定範囲を維持。持続/範囲/対象加算のQ279上限表は留保付き候補であり、本案から確定へ昇格させない。個別の制御時間・射線・認識・行動境界・最終対象上限を優先する。
- 加護の元成分がない攻撃・回復・支援を作らず、負補償・武器条件・副作用を解除しない。味方への効果は支援として分類し、自己への補償を味方へ伝播させない。
- 内部計算/保存は分数を保持し、表示だけ単位変換後の小数第2位を数学的ceilにする。U016/U044は解消済みで、丸めを未定へ戻さない。各案の「内部値 I/II/III」に分数を併記し、Rank表の百分率・ポイント等は説明用表示とする。
- 既存武器の生成基礎値・搭載IDを保持し、Skill効果は次出撃から新定義、進行中マッチは開始時定義を固定する。U041は解消済み。本案を進行中マッチへ適用しない。
- 再挑戦/同試行のWave開始からの再開/対象者の復帰を混同しない。本案は新たな使用回数・永続蓄積・回数再取得・直接CD還元を作らない。
- 各案で「提案キー」と記した成分名は、既存概念パラメータへ接続する新しい表現案。既存30キーへ登録済みという意味ではなく、現在の実装が読めるとの保証でもない。未対応の作用先は技術仕様どおり拒否し、読めないものを自動で有効化しない。
