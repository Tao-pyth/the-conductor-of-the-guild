## 1. 追加範囲と対象の決め方

武器は通常スキル0〜2個とUlt0〜1個を持ち、CDが満ち、対象・自動発動条件を満たした時に発動する。新しいMP、手動ボタン、ジョブ条件を追加しない。スキル定義は武器から独立し、同じSkillIDを複数武器で共有できる。

通常スキルのS1由来・S2由来という設計群と、実際の装備枠S1/S2を分ける。通常スキルをどちらの枠へ割り当てても、直接SkillID加護は同じIDへ作用する。UltはULT枠で扱う。

| 指定方法 | 本案の作用先 |
| --- | --- |
| 実割当slot指定 | 実際のS1・S2・ULTへ設定したスキル。由来武器や定義の主分類では判定しない。 |
| SkillID直接指定 | 指定した同じID。別武器がそのIDを持っても有効。由来武器の表記は整理用で、武器条件そのものにはしない。 |
| 素材由来の指定 | 合成した上位の各成分ごとに元のID・slot・適用条件を保持。同じ成分を両条件に一致しただけで2回数えない。 |

S1/S2/ULTそれぞれにCD短縮・回復速度の汎用経路があるため、150スキルの全IDを対象にできる強化経路を持つ。通常には25件の直接SkillID指定を設け、攻撃だけでなく回復・弱体・支援・持続へ分散する。UNIQUE50件はすべて異なる具体SkillIDを直接変更する。

## 2. 共通の計算・発動規約

### 2.1 CDの候補式と安全床

以下は親文書と共通化する調整案であり、確定した値とは扱わない。

- S1/S2の下限L=max(1秒, 元CD×10%)、ULTの下限L=max(10秒, 元CD×25%)。上限U=元CD×4。
- C1=Clamp(元CD−固定減算秒＋固定延長秒,L,U)
- C2=Clamp(C1×(1−短縮率＋延長率),L,U)
- 最終CD=Clamp(C2÷CD回復速度倍率,L,U)
- CD短縮率の候補上限80%。回復速度倍率は基準1、候補範囲0.25〜3。
- 回復速度は最終CDの割算へ1回だけ使い、CDゲージ進行へ二重適用しない。進行は0〜1を保持し、戦闘時間delta/最終CDで増やす。能力変化で進行を0へ戻さない。
- キャスト短縮も元の発動を0秒連打へ変えない。キャスト0のスキルに新たなキャストを作らず、共通キャスト下限を維持する。
- 使用中の直接CD還元を将来用いる場合も、元1行動につき1回・残り正規化量の最大25%という候補制限と、同castIDからの再還元禁止を使う。本SU50には無条件のCD全回復・再発動を入れない。

数値成分のCD_FIXED_DELTAは「加算」で負数が短縮、正数が延長を表す。表の「0.2秒短縮」と式の固定減算へ同じ値を2度投入しない。割合補正は0.05=5%の量であり、5ポイントの確率加算とは異なる。

### 2.2 元威力・元回復量と派生行動

- 表の「元威力」「元総威力」は、通常・上位加護の該当補正を適用した対象SkillIDの、1対象へ全hitが完了した場合の威力予算。複数対象全体の合計威力を、元対象数倍して無断に1体へ集めない。
- 「元回復量」は1対象へ全回復tickが完了した量。「元支援量」「元弱体強度」は各成分の差分量。中立の1倍、基礎能力値、型別上下限を拡縮しない。
- 元スキルにある条件・代償・副効果・状態解除は、表が明示して置換/削除したもの以外は保持する。支援を別対象へ移す場合も、元の正補正と代償を対応させて移す。山脈崩しの気絶、永巡の初回有効回復時の状態解除等を、威力/形状変更だけで消さない。
- SUが「置換」とした元ノードは残さない。「追加」と記したノードだけを追加する。全ノードは同じ元castIDを共有する。
- スキル由来の攻撃・回復は通常攻撃とは別。旧UQの「通常攻撃のみ」という条件を、新しいスキル全般へ勝手に広げない。通常スキル・Ult・通常攻撃を区別して照合する。
- スキルの派生hit・追撃・誘発回復・DOTは新しい自動スキル/Ultの発動元、CD還元の発動元、素材・経験値・恒久能力・通貨の生成元にならない。
- 元スキル1回の複数命中・複数撃破は、同じ固有変更を1回だけ起こす。例外の対象別計算も表の共通上限を守る。
- 対象・設置位置は元の認識・射程・行動境界内から自動決定する。新しい手動操作、地形・経路変更、射程外への無制限伝播は加えない。
- 回復・支援は生存味方のみ。HP0を復帰させず、恒久不利・衰弱を戦闘用回復で消さない。相手の最大HPを超える回復・永続盾は作らない。
- 一時弱体の消費は自分が付けた有効な既存状態1件に限り、同castで付与と消費を繰り返さない。状態が無効なら該当部分のみ不発。
- 強制終了時は元cast・ノード・回数記録を重複適用しない候補処理を使う。再挑戦時の消費・復元境界は既存確認事項のままで、本票から無断に確定しない。

### 2.3 合成・数値継承

新しい100レシピも、異種2加護の各Rank IIIから1個・1枠・Rank Iを生成する。III上限・例外なし、失敗なし、追加費用なし。SN/SH/SUは種類IDであり、新しいRank段階ではない。

上位SHの数値は素材IIIの成分をMergeしてI=2/3、II=1、III=4/3の差分量とする既存案を使う。固定値・加算型割合・乗算型を分け、元のSkillID・実slot・武器等の条件、負補償との対応を失わない。SHは前に定義したSHのみを参照し、SU/UQを素材にしない。

SUも素材の数値成分を同じ規約で継承し、表の固有変更を別の性能予算として評価する。素材の圧縮だけでQ124の「Iで維持〜やや減、IIで維持〜上昇」を達成したとは判定しない。固有変更・対象数・頻度・制約を含む比較は未検証である。

- 追加スキル/Ultの自動発動優先順、CD・キャスト下限、効果係数、合成係数、相互作用の数値は提案として評価する。

- 本案は新しいMP、永久成長・経験値生成、任意の手動再発動、装備変更、HP0復帰の例外を追加しない。コード・Issue・実行データは変更しない。
