- 作成日：2026-10-24。下記参照元hash時点の静的ビューであり、原マスターの変更は自動更新されない。
- 現行基準：v0.2.0。仕様資料・台帳の既存ファイル名は維持。
- 対応表： [検索用Excel](parameter_blessing_mapping.xlsx)。元の[加護マスター](guild_blessings_master_v0.1.0.xlsx)は読み取りのみで保全。
- 数値・名称・条件・レビュー入力は現Excelを優先し、旧中間JSONから上書きしていない。元8シートの全値・数式を監査用へ抽出した。
- 本表は定義の対応を調べる資料。既存453候補すべての採用・実装・性能検証を認定するものではない。

## 対応種別と読み方

| 種別 | 意味 |
| --- | --- |
| 直接 | 通常加護の数値成分。指定条件・対象SkillID・実割当枠を満たした場合だけ作用する。 |
| 継承 | 合成素材の現在IIIから継承した数値。元の条件・負補正・補償を残す。固有本文とは分ける。 |
| 補償リンク | `補償対応`で原負補正との対応を保持する。継承と両立する別の役割であり、主表では加算可能な独立総数へ足さない。 |
| 派生間接 | 能力派生式やCD計算を通じて別パラメータが変わる。元の値を派生先への直接加算値として転記しない。 |
| 固有本文参照 | UNIQUE本文に明示・参照される概念と動作分類を追跡する。投射物の存在だけで弾速補正、秒の記述だけで持続倍率、対象置換だけで対象上限bonusと判定しない。固有本文から汎用倍率を新設しない。 |
| 参考メタ | 効果量未定かつ初期対象外。未定を0効果へ置き換えない。 |
| 追加案参照 | BP36は未採用・抽選/合成未登録。既存453の対応数へ混ぜない。 |

正負は値の増減方向であり、有利・不利の同義語ではない。攻撃間隔・CDは小さいほど頻度が上がる。固定短縮量など非負の入力値に負の値を作って反対方向を表さない。

## 単位・型・計算の境界

- P06の最大HPという本体値（HP）と、加護が持つ割合補正を別列にした。固定加算・加算割合・乗算、pt・比率、効果範囲・射程・対象数を混ぜない。
- 技術登録の`crit-basis-points`は1bp=0.01%。加護の1ptは確率0.01=100bpに対応する。移動は1centi-tile=0.01マス、秒とmsは1000倍で換算する。
- `xp`/`required-xp`はLv/Rank、`resources`は拠点/マッチなど、所有先と用途で異なる実値を保持する。共通IDを持つことを同一プールの根拠にしない。
- `SKILL_*_BONUS`は対象SkillIDの実割当S1/S2/ULTへ解決する。武器整理群やカタログ提案枠で失効させず、同じ成分がIDと枠の両条件に一致しても1回だけ。
- `CD_FIXED_DELTA`は負を固定短縮量、正を固定延長量へ分ける。`RECOVERY_BONUS`は1+差分。`CAST_REDUCTION_RATE`は率を先に−1〜0.5へ制限した後、速度1/(1−率)へ変換する。
- 数値リンクの元Rank列・厳密原値列は抽出した監査値。換算列は補正量/倍率であり、最大HPやダメージの最終値ではない。厳密原値が元Excelで空欄のものは空欄を保持し、近似小数から正確な分数を捏造しない。
- [技術仕様](technical_specification.md)どおり、ゲームの内部計算・保存は分数を維持する。ゲーム表示時のみ単位変換後に小数第2位で数学的ceil（負数−1.234→−1.23）。本監査表の元値を表示丸めで書き換えない。
- `base_cd_sec`は定義入力、`effective_cd_sec`は計算結果、`cd_floor_sec`と共通硬直は安全制約。直接加護がないことを新たな不足としない。管理状態のRank/XP等も登録だけで直接操作を解禁しない。
